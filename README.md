# Микросервисная архитектура проекта "Маркетплейс билетов"

Проект по дисциплине «Микросервисная архитектура»

Группа: ТРПО23-1

**Команда:** Аюпова Ойдин, Ха Фам Минь Туан

## Описание проекта
Масштабируемый маркетплейс концертных билетов с высокой степенью конкурентности т.е. защита от задвоения мест, поддержкой распределенных транзакций, временной блокировкой мест через Redis и асинхронной доставкой уведомлений через брокер сообщений
